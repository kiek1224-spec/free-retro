실제 시간 사용

시간은 계속 흐릅니다. 프로필별로 보관하며 기기 시간은 바꾸지 않습니다. RTC가 없는 게임에는 효과가 없고, 코어에 따라 게임 재시작이 필요합니다.

화면과 캡처

치트·코어 옵션·키/패드 설정은 게임 화면 아래 EmulatorJS 메뉴에서 조절하세요. 시간 설정은 해당 코어가 제공할 때만 사용할 수 있습니다.

단축키와 입력 매크로

실제 버튼 입력을 최대 60초간 기록합니다. 재생 타이밍은 실시간 기준입니다.

Google Drive 연결 설정

Google Cloud에서 Drive API와 Picker API를 활성화하고 웹 OAuth 클라이언트를 만드세요. 이 사이트 주소를 승인된 JavaScript 원본에 등록해야 합니다.

클라이언트 비밀키는 필요 없습니다. 위 설정값만 이 브라우저에 보관하며 로그인 토큰은 메모리에서만 유지합니다.

Google 공식 설정 안내 ↗

로컬 데이터는 기기·브라우저마다 별개입니다. PC와 휴대폰 사이의 저장은 ‘저장 전체 백업’ 파일로 옮길 수도 있습니다. 자동 동기화는 로그인 후 앱을 열어 둔 동안 동작합니다. 닫힌 브라우저에서는 실행되지 않습니다.

같은 Google 계정과 OAuth 앱으로 연결한 휴대폰·PC에서 저장을 가져옵니다. 상태·게임 내 저장·RTC 설정을 앱 전용 공간에 전송하며 ROM은 업로드하지 않습니다. 이력은 덮어쓰거나 자동 삭제하지 않아 Drive 용량을 사용합니다.
