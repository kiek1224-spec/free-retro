# 플랫폼·폴더·아트워크 · 2026-10-09

사용자 첨부 Afterplay 화면의 플랫폼 탐색과 표지 배열을 참고해 기존 차콜/라임 디자인을 확장했습니다. 참고 화면의 게임 이미지는 가져오지 않았습니다.

## 구현

- Nintendo/Sony/Sega 10개 지원 플랫폼과 현재 게임 수. 기존 검색/컬렉션/폴더 필터와 함께 동작합니다. PC에는 스크롤 가능한 사이드바, 모바일에는 접힌 플랫폼 메뉴를 제공합니다.
- 파일 또는 디렉터리 선택 후 추가 창에서 컬렉션 폴더 선택/생성. 디렉터리 루트 이름 제안과 비ROM 파일 제외.
- 가져오기 목록 또는 기존 게임의 정리 창에서 표지 선택. 10 MB/40 MP 한도, 실제 PNG/JPEG/WebP 시그니처 검사, 긴 변 1280px 축소 및 재인코딩. IDB에는 Blob을 저장하고 화면용 URL은 교체/취소 시 해제합니다.
- 동일 SHA-256 ROM은 개인 설정을 유지하고 지정한 폴더/표지만 반영. 취소는 저장하지 않으며 실패 파일만 남겨 재시도할 수 있습니다.
- Drive 선택 동안 dialog 모달 top layer 해제/복원. 취소 후 늦은 응답 무시. 다운로드와 응답 본문에 30초 abort timeout.

## 확인한 결과

현재 localhost에서 파일 선택기를 통해 자체 제작 NES ROM 두 개와 자체 PNG가 있는 디렉터리를 선택했습니다. ROM 2개 선택, 이미지/문서 2개 제외, `Arcade Picks` 이름 제안과 생성, 한 게임의 표지 Blob 저장을 확인했습니다. 새로고침 후에도 표지가 표시됐습니다. 기존 게임의 기본 표지 버튼을 누르고 편집을 취소한 뒤 원래 표지가 유지되는 것도 확인했습니다.

플랫폼 클릭으로 GBA 4개/NES 4개 필터링, 플랫폼 수 10개, 폴더 필터를 확인했습니다. PC 1280px의 clientWidth/scrollWidth는 1265px로 동일합니다. 모바일 390px의 폭은 둘 다 375px이며 카드 166.5px 2열, 가져오기 dialog 358px, 표지 편집 창은 가로 넘침 없이 표시됐습니다. 브라우저 오류 로그는 없었습니다.

Node 단위 검사 36/36 통과: ROM 동일성, 폴더 계획, 개인 설정 보존, 이미지 검사/변환, Drive 취소/timeout/모달 복구와 늦은 응답 방어 및 기존 RTC/동기화 검사를 포함합니다. 실행 결과는 library-unit.txt. 사용자 표지가 제목을 덮지 않도록 카드 높이를 통일하고 이미지 박스를 제한했습니다. PC 이미지 높이 208px(카드 아트 225px), 모바일 179px(카드 아트 190px)으로 제목 위에 끝나는 것을 확인했습니다.

화면 증거: library-platforms-artwork.png, library-import.png, library-mobile-import.png, library-mobile.png (로컬 파일, Git 제외).

## 검증 한계

기존 게임의 새로운 표지를 파일 선택기로 지정하는 추가 검사는 브라우저 도구가 권한 거부로 차단했습니다. 해당 파일 선택을 재시도하거나 우회하지 않았습니다. 테스트 HTML `tests/library-e2e.html`은 작성 및 문법 확인만 했으며 이번 세션에서는 실행하지 않았습니다. PNG/JPEG/WebP 검사 및 변환의 성공/실패는 Node 모의 canvas 테스트와 완료된 가져오기 수동 검사로 확인했습니다.

실제 Google Cloud 인증 정보가 없어 Google Picker 모달 표시와 실서버 다운로드는 미검증입니다. 실제 휴대폰은 사용하지 않았으며 모바일 확인은 뷰포트 검증입니다. 이번 UI 작업에서 실제 NES/GBA 코어 검사는 다시 실행하지 않았습니다. 앞선 코어 검증 결과는 기존 verification 기록을 참고하세요.
